# پروژهٔ «آزمون یار» — سایت + ایجنت سئو

پروژهٔ مستقل برای اپ `com.driver_azmon` («آزمون آیین‌نامه رانندگی ۱۴۰۵»).
دو بخش دارد:

```
azmoon-yar-seo/
├─ index.html · sitemap.xml · robots.txt   ← سایت لندینگ (این را آپلود می‌کنی)
├─ blog/                                    ← مقالات (ایجنت می‌سازد)
├─ agent/                                   ← خودِ ایجنت سئو
│   ├─ seo_agent.dart                       ← کد (Dart خالص)
│   ├─ config.json                          ← تنظیمات
│   ├─ keywords.json                        ← صف کلمات کلیدی
│   └─ README-FA.md                         ← راهنمای ایجنت
├─ run_seo_agent.ps1                        ← اجرا روی ویندوز / Task Scheduler
└─ .github/workflows/seo-agent.yml          ← اجرای روزانه در GitHub Actions
```

اجرای سریع ایجنت:

```powershell
dart run agent/seo_agent.dart run
```

## راهنمای لندینگ

این پوشه یک لندینگ آماده‌ی سئوشده برای اپ `com.driver_azmon` («آزمون آیین‌نامه رانندگی ۱۴۰۵») است.

## ۱) پیش از آپلود، این‌ها را جایگزین کن
در فایل `index.html`:
- `https://example.ir/` → دامنه‌ی واقعی خودت (هم در `canonical`، هم `og:url`، هم اسکیمای `url`).
- لینک کافه‌بازار (`#bazaar`) → لینک واقعی صفحه‌ی اپ در کافه‌بازار.
- اگر اطلاعات امتیاز/دانلود عوض شد، مقدار `aggregateRating` را به‌روز کن.
در فایل‌های `robots.txt` و `sitemap.xml` هم `example.ir` را با دامنه‌ی خودت عوض کن.

## ۲) کجا آپلود کنم؟
- **هاست ایرانی** (مثل لیارا، پارس‌پک، ایران‌سرور) → برای کاربر ایرانی سریع‌تر و پایدارتر.
- یا **GitHub Pages / Cloudflare Pages** → رایگان، ولی ممکن است از ایران کند/فیلتر باشد.
- فقط فایل‌های این پوشه را در ریشه‌ی دامنه آپلود کن؛ آدرس سایت باید `https://دامنه/` باشد.

## ۳) مراحل ثبت در گوگل (ایندکس شدن)
1. در [Google Search Console](https://search.google.com/search-console) دامنه را ثبت و مالکیت را تأیید کن.
2. `sitemap.xml` را ثبت کن (بخش Sitemaps).
3. صفحه‌ی اصلی را با **URL Inspection → Request Indexing** معرفی کن.
4. در [Bing Webmaster Tools](https://www.bing.com/webmasters) هم ثبت کن.
5. با این جست‌وجو بررسی کن: `site:دامنه‌ی-خودت.ir`
6. لینک اپ در مایکت را با همین روش پیگیری کن: `site:myket.ir com.driver_azmon`

## ۴) کارهای بعدی که رتبه را بالا می‌برد
- یک **وبلاگ** زیر همان دامنه بساز و مقالات واقعی بنویس:
  «نمونه سوالات آیین نامه ۱۴۰۵»، «سوالات فنی آیین نامه»، «تابلوهای راهنمایی و رانندگی».
- از هر مقاله به صفحه‌ی اصلی و به لینک مایکت/کافه‌بازار لینک بده.
- ویدیوی معرفی در **آپارات** با لینک مایکت در توضیحات.
- بایو **اینستاگرام/تلگرام** با لینک سایت.
- **نام برند را پایدار کن**: به‌جای «...۱۴۰۵» همیشه «آزمون یار» را نگه دار و سال را فقط در محتوا به‌روز کن.

## ۵) نکته‌ی مهم
هیچ ابزاری نمی‌تواند گوگل را مجبور کند. این لندینگ **پایه** است؛ رتبه از ترکیب
«سایت خودت + محتوای واقعی + بکلینک + جست‌وجوی برندی» می‌آید و چند هفته تا چند ماه زمان می‌برد.
